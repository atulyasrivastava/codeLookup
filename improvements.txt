Hybrid search — combine keyword/BM25 with vector search; pure embeddings occasionally miss exact-name matches
Re-ranking — a cross-encoder re-ranker on top-k candidates would improve precision, especially on borderline queries
Robust injection detection — current guard is substring-based; a real system needs an LLM-based classifier or structural separation of instructions from retrieved content (e.g., via tool-use APIs), not phrase matching
Larger eval set — 8 questions is a starting point, not a benchmark; needs 50+ for real confidence
Full containerization — Qdrant runs in Docker, but the app itself doesn't yet; needs a docker-compose.yml for one-command deployment
Real Azure OpenAI integration — currently a designed-for abstraction, not a tested connection; needs managed identity auth, private endpoint/VNet integration, and content-filtering policy configuration
Caching — repeated/similar queries currently re-embed from scratch; a semantic cache would cut cost and latency
Incremental re-indexing — right now, indexing wipes and rebuilds the whole collection every run; production would need to detect changed files and re-embed only those
Rate limiting and auth — no protection currently against abuse if this were exposed as a real service
Monitoring/alerting on top of the audit log — logging exists, but nothing currently watches those logs for anomalies (spike in latency, spike in flagged chunks, etc.)
